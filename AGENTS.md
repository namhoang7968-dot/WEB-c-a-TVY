# Quy tắc thiết kế & phát triển Creator Studio Dashboard (WEBTVY)

- **Frontend Tech Stack**: React (Vite) + Tailwind CSS + Lucide Icons + Recharts.
- **Backend & Database**: Supabase (PostgreSQL) + Row Level Security (RLS).
- **Design Standards**: Áp dụng các quy tắc UI/UX từ các skill: Hallmark (design system có chiều sâu), Taste Skill (anti-slop, layout 1 section/màn hình), và unslop (loại bỏ màu lòe loẹt, tinh chỉnh spacing, typography chuẩn xác).
